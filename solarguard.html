La energía se cuida.
La seguridad también.

SolarGuard es un sistema de seguridad diseñado para detectar movimientos, golpes y vibraciones en instalaciones solares.

Conocer el proyecto →

01 / EL PROBLEMA

¿Qué queremos resolver?

En las zonas rurales de la estepa de Chubut, algunas escuelas dependen de la energía solar para tener electricidad. Sus paneles y baterías pueden sufrir robos, vandalismo o daños causados por animales. Por eso proponemos crear un sistema que detecte movimientos o golpes y avise cuando la instalación se encuentre en riesgo.

02 / NUESTRA SOLUCIÓN

Una alerta a tiempo puede hacer la diferencia.

SolarGuard combina sensores conectados a una placa Arduino Uno. Cuando detecta movimiento o vibraciones, activa una alarma sonora y muestra un mensaje de alerta en una pantalla LCD.

03 / LOS COMPONENTES

¿Qué usamos para construirlo?

Arduino Uno

Recibe las señales de los sensores y controla las alertas.

Sensor PIR HC-SR501

Detecta la presencia y el movimiento de personas o animales.

Sensor SW-420

Detecta golpes y vibraciones que pueden indicar una manipulación de los equipos.

Buzzer activo 5V

Emite una alarma sonora cuando el sistema detecta una posible amenaza.

Pantalla LCD 16x2

Muestra mensajes para informar al usuario sobre el estado del sistema.

04 / FUNCIONAMIENTO

¿Cómo funciona SolarGuard?

01. Detectar

Los sensores detectan movimientos, golpes o vibraciones.

02. Procesar

Arduino recibe las señales y procesa la información.

03. Alertar

El buzzer suena y la pantalla LCD muestra el mensaje correspondiente.
